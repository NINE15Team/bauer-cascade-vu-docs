Operations

Standing up and maintaining VU products on Bauer CA. All values below are from live ca.bauer.com, 26 August 2026 — not from git JSON and not from the spreadsheet.

Prerequisite

VU must issue a data_variant and a product slug, and confirm which engine environment it is built on. Without those you have a PDP, not a customizer.

Add a product

  1. VU sideThey configure the 3D product and return data_variant (e.g. bauer-flylite), product slug (e.g. vapor), and the ready environment — usually staging first.

  2. Shopify productCreate on Bauer store. Record product ID and variant IDs; steel has one variant per size. Set product type to MyBauer-Skate or MyBauer-Steel — the type drives lead-time selection.

  3. TemplateTheme Editor → the product (or a dedicated product template) → add section VU Customizer. Not the vu_customizer block on main-product.

  4. TriggerA control with name="showmodal" on the same document. The rich-text “VU Customizer Trigger” block does this when Attribute = showmodal.

  5. MetafieldsSet custom.product_category and custom.customization_type. Leave estimated_delivery blank unless this product genuinely differs.

  6. Verify theme settingsLive CA: vu_customizer_country = ca, vu_customizer_environment = production.

  7. Smoke test on a draft themeOpen the modal, change a colour, reach the last tab, add to cart. Confirm the cart line carries estimated delivery, _CustomerRequestDate, _LeadTime and both SAP keys. Sentry environment should read production-draft.

  8. Record the IDsUpdate the spreadsheet and the catalog table below.

Country is shop-wide

One value per theme, and VU derives pricing and option sets from it. CA must stay ca. Flipping it to test and forgetting to revert silently changes pricing on every customizer PDP.

SAP keys

The underscore prefix keeps _Custom Product Category, _Customization Level, _CustomerRequestDate and _LeadTime off the storefront line item. The spelling is an SAP contract — renaming one produces a successful order with bad manufacturing data.

Lead time and cart attributes

On customizer.scene-rendered the snippet builds window.customizerLineAttributes:

  1. Translated estimated delivery date → MM/DD/YYYY, weekdays only
  2. _CustomerRequestDate — same date
  3. _LeadTime — integer days
  4. _Custom Product Category — if the metafield is set
  5. _Customization Level — if the metafield is set
days = product.metafields.estimated_delivery
     ?? (product.type == 'MyBauer-Steel'
           ? custom_blade_estimated_delivery
           : custom_skate_estimated_delivery)

on customizer.recipe-updates-complete:
  if recipe.color_zones.value.code ∈ section.delivery_custom_zone_codes
     days = custom_skate_customColor_estimated_delivery
     → re-render date + #expectedDelivery

CTA and shared links

vu_main.js binds every [name="showmodal"] to openPopUpModal. The section can sit hidden on the product template while the trigger lives in a hero elsewhere on the same document.

?recipe_id= on the URL auto-opens the modal and loads that recipe, then strips recipe_id and variant from the address bar. Print is customizer.printSummary() from #printButton.

Klaviyo

Closing the modal with unsaved progress, or using Share, posts to:

https://a.klaviyo.com/client/events/?company_id={{ settings.klaviyo_account_id }}
https://a.klaviyo.com/client/subscriptions/?company_id=… + list {{ settings.klaviyo_list_id }}

Payload includes recipe fields (colour, sizes, tongue, fit) and a resume URL with ?recipe_id=. This is Bauer's Klaviyo account. Live IDs are in Theme settings, not git.

Success and failure toasts use the missing email_success / email_fail keys — see below.

Locales

Namespace vu.vu-customizer.* in sites/bauer-ca/locales/, not _shared. French PDPs set data-locale="fr-ca"; VU must have that locale built.

Four keys referenced but undefined

load_fail, try_again, email_success, email_fail are called by the snippet and absent from both en.default.json and fr.json. Shopify renders the key path instead, including inside the load-failure UI. Verified August 2026.

Categories not on VU

Goalie gear and sticks are not live on VU. Their current state, the partial shell already in the skate files, and the next steps for each are on Upcoming projects.

Goalie steel is not goalie gear

Goalie steel — LS Pulse Ti and LS 5G, listed above — shipped and is live. Goalie gear is pads, blockers and catchers, and is not built.

Source of truth

Product / Customizer Details (Google Sheet) holds IDs, data variants, slugs, environments and preview URLs.

Where the sheet and this page disagree, believe the live PDP. Known sheet errors: Fuse carries Hyperlite 2's product ID; the Hyperlite 2 custom URL is 404; steel URLs are marked NA but exist. Other markets: use the sheet — their JSON is not in this repo.
