Goalie gear

Started 2025 · paused

Current state

Pads, blockers and catchers were kicked off in 2025 and shelved before launch. Nobody has worked on it since. What shoppers see for that category today is still the Spectrum customizer, reached through settings.custom_goalie_gear_host (default cdn.spectrumcustomizer.com) and the page.My-Bauer-Goalie-* templates. None of that is VU and none of it is maintained as part of this integration.

What already exists in the theme

This is the important part: do not start a new customizer. A partial shell is already committed inside the skate files and will be picked up automatically once VU issue the product configuration.

Outstanding work and next steps

  1. VU configuration firstThere is no data_variant and no product slug for gear. Until VU build the templates in VU Admin and issue those, no amount of theme work moves this forward. This is the gate.

  2. Confirm the tab structureThe existing accordion code assumes tabs named catcher_specs, pad_specs and blocker_specs. Check those names survived into VU's current template design before trusting the CSS.

  3. Agree the SAP mappingcustom.product_category currently has Skate, Steel and Goalie Steel in use. Gear needs its own value agreed with whoever owns the SAP side, plus confirmation that _Customization Level stays CUSTOM.

  4. Decide the lead timeGear is neither a skate nor a blade, so the existing two-branch logic does not cover it. Either add a branch on product type or set the estimated_delivery metafield per product.

  5. Finish the shell, then migrate off SpectrumComplete the CSS and JS already in place, launch alongside Spectrum, then retire the page.My-Bauer-Goalie-* templates and custom_goalie_gear_host.

Scope note

Goalie gear is a bigger customizer than a skate — three product families, each with their own spec panels. Treat the existing shell as a head start on layout, not as most of the work.

The flex guide snippet and metaobject are the only pre-existing scaffolding, and the snippet needs its placeholder copy replaced.

Two name traps

Goalie steel is not goalie gear

Goalie steel — LS Pulse Ti and LS 5G, data_variant goalie-steel-b2c — shipped, works, and is live today. Goalie gear is pads, blockers and catchers, and is not built. The two sound identical in a meeting and are completely different states of done.

Spectrum is not VU

Both categories still have working customizers on the site today, built by the previous vendor. Finding a live goalie or stick customizer is not evidence that VU work exists. Check which host the page loads.
